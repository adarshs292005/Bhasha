# Bhasha — AI-Powered Sign Language Communication Platform

Bhasha is an accessibility project designed to bridge communication between Indian Sign Language (ISL) users and spoken-language users using computer vision and machine learning.

## Features

- Sign Language to Text
- Text to Speech
- Speech to Text
- Speech to Sign Language (planned/in development)
- Real-time camera-based hand tracking
- Sign dataset collection and model development
